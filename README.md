# UModel Importer Plugin

![Preview]([preview.png](https://github.com/ST-Jie-Ge/uemodel-import-plugins/blob/main/viv.jpg?raw=true))

## 中文

这是一个让 UModel 可以被导入虚幻引擎的插件。

目前仅兼容 **UE 4.27**。

修改自：[URL](https://github.com/andr1ww/UE4Format)

### 修复

- 修复了模型文件错误会引发 UE 崩溃的问题
- 修复了原插件材质定位异常的问题
- 修复了代码本身的逻辑问题

### 问题反馈

遇到问题请附上 **Log**，以方便诊断问题。

---

## English

This is a plugin that allows UModel files to be imported into Unreal Engine.

Currently only compatible with **UE 4.27**.

Modified from: [URL](https://github.com/andr1ww/UE4Format)

### Fixes

- Fixed an issue where invalid model files could cause UE to crash
- Fixed material path resolution issues in the original plugin
- Fixed logic issues in the original code

### Issues

If you encounter any issues, please include the **Log** to help diagnose the problem.
